# Xu 后续路线

本文记录尚未实现的计划。完成一项后从本文件移除，并在 `CHANGELOG.md` 中记录。

## P2：效率与差异化

### 1. 多标签同步输入

- 可选择多个已打开的 SSH 标签同步输入。
- 默认关闭，开启时显示明显警告。
- 关闭标签或断开连接时自动移出同步组。

### 2. 终端分屏

- 同一窗口内左右或上下分屏。
- 分屏布局随工作区保存和恢复。
- 保持现有顶部标签和浮动编辑器行为不变。

### 3. 远程服务器之间直接传输

- 通过一台中转 SSH 服务器在两个远端 SFTP 之间复制文件。
- 优先使用流式中转，避免先完整下载到本机。
- 支持目录、暂停、继续和冲突策略。

### 4. 服务器总览与告警

- 汇总所有已连接服务器的 CPU、内存、磁盘和延迟。
- 支持阈值告警和断线提醒。
- 告警只在状态变化时通知，避免持续刷屏。

## 明确不做

- 不在传输历史中保存文件内容。
- 不把密码或私钥写入 SQLite。
- 不在用户未确认时自动结束正在运行的 Xu 进程。
- 不在未提示风险的情况下自动信任变化后的主机密钥。
