# Xu 后续路线

本文记录尚未实现的计划。完成一项后从本文件移除，并在 `CHANGELOG.md` 中记录。

## P1：生产可用

### 1. 认证体系二期

- 支持选择任意私钥文件，不再限制 `~/.xu/keys` 下的固定文件名。
- 支持带口令私钥，并在应用内安全询问口令。
- 支持 keyboard-interactive / MFA 登录。
- 增加密钥导入与生成入口，可查看公钥指纹并复制公钥。

验收标准：

- 密码、私钥、Agent、MFA 可在连接配置中明确选择。
- 私钥口令不出现在日志、SQLite 或命令行参数中。

### 2. known_hosts 管理

- 在设置或连接详情中列出现有主机密钥及指纹。
- 支持删除已知主机密钥。
- 服务器重装后，允许通过二次确认更新指纹。

验收标准：

- 用户不再需要手工修改 `xu.db` 才能处理主机密钥变化。
- 更新指纹必须显示旧值和新值，并明确提示安全风险。

### 3. 工作区恢复

- 记录真实的最近使用时间，修正当前按名称排序的“最近连接”。
- 保存工作区：一组服务器、标签顺序和需要自动启动的隧道。
- 应用重启后可恢复上次打开的服务器标签。
- 自动连接遇到 MFA 或口令时暂停等待用户输入。

### 4. 连接与设置备份

- 导出连接、分组、快捷命令和端口转发规则，不导出明文密码。
- 支持导入 Xu 自己的导出文件和标准 OpenSSH `config`。
- 导入时提供跳过、覆盖、重命名冲突选项。

### 5. 传输队列持久化

- 应用重启后保留等待中、已暂停和失败的传输任务。
- 保存任务来源、目标、冲突策略和进度信息。
- 重启后的“继续”应复用已有 `.part` / `.xu-part` 文件。
- 传输历史与任务状态分开存储，历史仍只保留最近 7 天。

## P2：效率与差异化

### 6. 多标签同步输入

- 可选择多个已打开的 SSH 标签同步输入。
- 默认关闭，开启时显示明显警告。
- 关闭标签或断开连接时自动移出同步组。

### 7. 终端分屏

- 同一窗口内左右或上下分屏。
- 分屏布局随工作区保存和恢复。
- 保持现有顶部标签和浮动编辑器行为不变。

### 8. 远程服务器之间直接传输

- 通过一台中转 SSH 服务器在两个远端 SFTP 之间复制文件。
- 优先使用流式中转，避免先完整下载到本机。
- 支持目录、暂停、继续和冲突策略。

### 9. 服务器总览与告警

- 汇总所有已连接服务器的 CPU、内存、磁盘和延迟。
- 支持阈值告警和断线提醒。
- 告警只在状态变化时通知，避免持续刷屏。

## 明确不做

- 不在传输历史中保存文件内容。
- 不把密码或私钥写入 SQLite。
- 不在用户未确认时自动结束正在运行的 Xu 进程。
- 不在未提示风险的情况下自动信任变化后的主机密钥。
